ALL-IN-ONE PATCH
=================

Copia TUTTO il contenuto di questo ZIP direttamente in C:\xampp\htdocs\attrezzature2\ (sovrascrivi quando richiesto).
File inclusi:
- includes/session_boot.php
- includes/auth_config.php
- includes/require_login.php
- includes/user_badge.php
- logout.php (root)
- index.php (root)
- pages/catalogo.php
- pages/dashboard.php

Dopo la copia:
1) Apri http://localhost/attrezzature2/
2) Verifica badge in alto; catalogo pubblico con badge; dashboard protetta.
3) Se avevi un tuo catalogo, incolla il contenuto nel nuovo pages/catalogo.php sotto il badge.
